🧠 作答錦囊

呢幾招係攞高分嘅關鍵，開考前一定要記住
1選擇題：用「刪除法」▾

唔好一開始就揀「似樣」嘅答案。先將明顯錯嘅選項刪走，剩低兩個再逐個字比較。

  • 留意有無「唔」「不」「沒」呢類否定字，好多時一加咗意思就反轉。
  • 成語題睇對象：寫人嘅成語唔可以形容事物；寫壞人嘅成語唔可以形容好人。
  • 唔肯定都一定要填，錯咗唔扣分，空白就一定零分。
2改寫句子：先搵「人」同「話」▾

直述句 ↔ 轉述句係今次嘅重點。改寫時逐樣核對四件事，唔會漏：

  • 人稱：我→他／她；你→我；我們→他們
  • 標點：「」逗號 → 無引號
  • 近指變遠指：這→那、今天→那天、來→去
  • 動詞：說→說／告訴；問道→問
3閱讀理解：答案多數在文中▾
  • 問「為什麼」→ 找原因句，通常有「因為」「由於」。
  • 問「怎樣／如何」→ 找動作詞，抄原文最穩陣。
  • 問「人物的性格」→ 要用成語或形容詞，再舉文中一個例子做證據。
  • 答題要寫完整句子，唔好只寫兩三個字。
4作文（寫人）：五官＋動作＋一件事▾

寫人唔係淨係講「她很好」。用呢個三段公式：

  • 第一段：外貌（眼睛、眉毛、鼻子、嘴巴、牙齒）＋ 一句整體印象
  • 第二段：一件具體的事，寫埋語言、神情、動作
  • 第三段：首尾呼應，講你對佢的感受

記住：成語唔好塞太多，一篇文章用 3–5 個就夠，用錯咗反而扣分。

✏️ 三大重點句式

課本「句子表」+ 語文基礎知識
A「……不過……」▾

作用：先講一個情況，再用「不過」轉折，講出相反或者不同嘅情況。佢係「轉折關係」嘅句子。

課文句子（第二課〈相架〉）哥哥、妹妹和我湊錢買禮物給媽媽，不過我們的錢不多，只能夠買一個很小的相架。
應用 1這件外套的款式很漂亮，不過價錢太貴了。
應用 2我已經很努力溫習，不過還是有幾題不懂。
應用 3妹妹很想養一隻小狗，不過媽媽不答應。
  • 「不過」放喺兩個分句中間，前面用逗號。
  • 前後兩句意思要相反：好 ↔ 壞、想 ↔ 唔能。
B「無論……都……」▾

作用：表示在任何情況下結果都一樣，係「條件關係」嘅句子。「無論」後面通常配「怎樣」「什麼」「誰」「多」等疑問詞。

課文句子（第五課〈媽媽，您也長大了！〉）可是無論我怎樣用勁，都不能發出一點兒聲音。
應用 1無論天氣怎樣寒冷，爸爸都會送我上學。
應用 2無論遇到什麼困難，我們都不應該放棄。
應用 3無論這道題多難，哥哥都能想辦法解決。
易錯位✗ 無論我怎樣用勁，不能發出聲音。　→ 漏咗「都」。
✓ 無論我怎樣用勁，都不能發出聲音。
  • 「無論」同「都」一定要成對出現，缺一不可。
  • 「無論」後面唔可以接「我喜歡去」呢類確定嘅事，要接不確定嘅情況。
C直述句 ↔ 轉述句▾

直述句：直接引述人物原本講嘅說話，用引號「」。
轉述句：由第三者將說話轉告別人，唔用引號。

課文句子（第七課〈一枚銀幣〉）旅人這樣稱讚銀幣，說：「你是多麼善良、誠實的銀幣啊！」

他將我稱為善良、誠實的銀幣……

四步改寫法（每步都要做）：

① 人稱我 → 他／她　｜　你 → 我　｜　我們 → 他們　｜　我的 → 他的
② 標點去掉「」，引號前嘅「，」改成「，」；句號照留
③ 指示詞這 → 那　｜　這裡 → 那裡　｜　今天 → 那天　｜　明天 → 第二天　｜　來 → 去
④ 動詞說：「…」→ 說…　｜　問道：「…」→ 問…　｜　告訴我：「…」→ 告訴我…

對照例子：

直述媽媽說：「我明天來接你放學。」
轉述媽媽說，她第二天去接我放學。
直述老師問我們：「你們昨天有做功課嗎？」
轉述老師問我們那天有沒有做功課。
直述弟弟大聲說：「我最喜歡這本書！」
轉述弟弟大聲說，他最喜歡那本書。
易錯位✗ 媽媽說她明天來接我放學。　→ 「來」「明天」冇改。
✓ 媽媽說她第二天去接我放學。
🎯口訣：「人稱改、引號拆、這變那、來說去」——心中數住四步，就唔會漏。

💡 語文知識

三個單元要考嘅寫作手法同文章知識
1記敘文的要素（六要素）▾

記敘文即係講一件事嘅文章。要講得清楚，一定要有六個要素：

🕐時間
幾時發生？
📍地點
喺邊度發生？
🙋人物
有邊個？
🎬起因
點解會發生？
⚙️經過
事情怎樣發展？
🏁結果
最後變成點？
用〈相架〉睇六要素 時間：母親節前　地點：家、商店
人物：哥哥、妹妹、我、媽媽　起因：想送媽媽禮物
經過：三兄妹湊錢，錢不多，只買到一個很小的相架
結果：媽媽很歡喜，覺得禮物很珍貴
🎯「時間＋地點＋人物」通常喺文章開頭；「經過」佔最多段落；「結果」喺結尾。答題時按呢個次序搵，一定搵得到。
2順敘 與 倒敘▾
順敘

按住事情發生嘅先後次序寫：先發生嘅先寫，後發生嘅後寫。

👉 好似一條直線：過去 → 現在 → 未來

倒敘

先寫結果或者最難忘嘅一幕，再回頭講件事嘅經過。

👉 好似電影：先播結局，再倒帶

倒敘嘅開頭（第七課〈一枚銀幣〉嘅味道）看着這枚閃閃發亮的銀幣，我又想起那天在火車站發生的事……
易錯位倒敘唔係「亂寫」。倒敘完一定要有「時間跳返去」嘅句子，例如「記得那天……」「原來，事情是這樣的……」，最後先回到現在。
  • 見到「想起」「記得」「這件事發生在……」開頭 → 多數係倒敘。
  • 見到「後來」「接着」「第二天」一樣樣講落去 → 多數係順敘。
3擬人法▾

定義：把物（動物、植物、死物）當作人一樣，俾佢有人嘅動作、表情、說話或者思想。

課文例子（第一課〈白雲〉）白雲像一個魔術師，一時變成小狗，一時變成大象，還笑着向我們招手。
其他例子小草從泥土裏探出頭來偷看。
風唱着歌跑過田野。
太陽公公笑呵呵地升起來。
分辨：擬人 vs 比喻 ✗ 月亮像一個大銀盤。 → 有「像」，係明喻，唔係擬人。
✓ 月亮偷偷地從雲裏探出臉來。 → 月亮有人嘅動作，係擬人。
🎯一句認出擬人：句子主語係「物」，但動詞／形容詞係人才做得到嘅（笑、說、哭、招手、睡覺、生氣、害羞）。
4排比▾

定義：把三個或以上結構相似、字數相近嘅句子排埋一齊，加強氣勢同節奏。

語文基礎知識：排比公園裏，有人在跑步，有人在打球，有人在聊天。
其他例子春天來了，花開了，草綠了，燕子也回來了。
他喜歡讀書，喜歡畫畫，喜歡唱歌。
分辨：排比 vs 對比排比要三句或以上、結構相同；只有兩句、意思相反嘅，係「對比」或者「對偶」，唔係排比。
5首尾呼應▾

定義：文章開頭同結尾寫相似嘅內容、句子或者情境，令文章首尾連貫、結構完整。

例子 開頭：窗外下着蒙蒙細雨，我又想起那隻大白鵝。
── 中間寫故事 ──
結尾：雨停了，我望着窗外，那隻大白鵝的樣子又浮現在眼前。
  • 好處：結構完整、突出主題、令人印象深刻。
  • 寫作時記住：結尾要回應開頭嘅景物或者句子，唔好開頭講雨、結尾講雪。
🎯答題問「這種寫法有甚麼好處？」，答：「首尾呼應，使文章結構完整，並突出主題。」呢句幾乎每次都可以用。
6童話的特點▾

童話係一種幻想故事，多數適合小朋友睇。三個單元入面，第三單元「神奇的魔杖」就係童話故事欣賞。

  • 豐富的想像：會說話的動物、會飛的魔杖、回音堡……現實冇嘅都可以出現。
  • 萬物有靈：動物、植物、死物都會講嘢、有感情（同擬人有關）。
  • 教人道理：童話多數背後有一個訊息，例如要善良、誠實。
  • 誇張有趣：情節同人物都有少少誇張，讀落去好笑又神奇。
課文（第七課〈一枚銀幣〉）銀幣本身唔會講話，但喺童話入面，佢會訴說自己的遭遇，仲會評價旅人係唔係善良——呢啲就係童話嘅「想像」同「萬物有靈」。
🎯問「童話有甚麼特點」，最少寫兩個：想像豐富、萬物有靈、有教育意義（教人道理）、情節誇張有趣。
7多音字▾

同一個字有兩個或以上讀音，意思亦都唔同。今次範圍入面成日出現嘅多音字：

樂快樂（lok6）　音樂（ngok6）
長長大（zoeng2）　長短（coeng4）
重重複（cung4）　重要（zung6）
行行走（hang4）　銀行（hong4）
好好人（hou2）　喜好（hou3）
數數目（sou3）　數星星（sou2）
調調查（diu6）　調整（tiu4）
中中間（zung1）　中獎（zung3）
🎧多音字小百科：多音字嘅讀音要跟意思走。做題時先讀成句，再判斷意思，唔好死記單字。答題時如果要用拼音，記得寫埋聲調。

⚠️用成語三大忌：① 唔好形容錯對象（「垂涎三尺」形容很想吃，唔可以形容人靚）；② 唔好連用太多；③ 唔好寫錯字——常見錯字：全神貫注（唔係「灌」）、一絲不苟（唔係「狗」）、不辭勞苦（唔係「詞」）。

🖊️ 寫人篇 · 外貌描寫

作文「寫人」常用詞語庫 + 範句
三段公式（照住寫就有分）
1️⃣開頭：外貌＋印象
寫眼睛、眉毛、鼻子、嘴巴、牙齒、耳朵，最後加一句整體感覺：「她給人的第一印象是……」。
2️⃣中間：一件事＋言行
用一件具體嘅事，寫佢講咗乜、表情點、做咗乜動作。呢段最長，要有對話。
3️⃣結尾：感受＋首尾呼應
講你對佢嘅感受，並回應開頭嗰個外貌特徵或者情境。

🎯高分秘訣

每一科最容易失分的地方。考前十分鐘，只看這一頁就夠。

  1. 選擇題：先刪走明顯錯的剩低兩個再逐個字比較。特別留意「不、沒、未」這類否定字——加了一個字，意思就完全反轉。
  2. 成語要看對象形容外貌神態的成語，不可以形容事物；形容壞人的成語，不可以形容好人。分錯對象就沒有分。
  3. 直述改轉述：四樣都要改① 人稱（我→他／她，你→我，我們→他們）② 標點（拆走引號）③ 指示詞（這→那、今天→那天、來→去）④ 動詞（說→說、問道→問）。漏一樣就扣分。
  4. 閱讀理解：答案多數在文中問「為什麼」，找「因為」或「由於」的句子；問「怎樣／如何」，找動詞，抄原文最穩；問人物性格，要用成語或形容詞，再舉文中一個例子做證據。
  5. 不會的題目也要填錯了不扣分，空白一定零分。先做有把握的，再回頭想。
  1. Present tense 的 -sI / you / we / they 用原形；he / she / it 加 -s。拼法：一般加 -s；字尾是 s、sh、ch、x、o 加 -es（go→goes, watch→watches）；輔音 + y 變 ies（fly→flies）；have 變 has。
  2. 問句和否定句：Do / Does + 原形動詞Does she go jogging?（不是 goes）· She doesn't go jogging. 一用 Do / Does，後面的動詞就回到原形。
  3. should / should not + 原形動詞should 永遠不變形，沒有 shoulds、shoulded。它後面一定接原形：We should not make fun of each other.
  4. 比較：兩個用 -er than，三個或以上用 the -est形容詞較長時，用 more … than / the most …。看清楚題目在比較幾樣東西。
  5. 默書：用 Spelling 模式自測先揭開字卡讀一次，再蓋住解釋，自己打出來。拼錯的字寫三次。
  1. 除法驗算：30 秒保命商 × 除數 + 餘數 = 被除數。做完每一條除法，都用這個方法倒查一次。
  2. 整除規則，看個位和數字和2：個位是 0、2、4、6、8｜5：個位是 0 或 5｜10：個位是 0｜3：各位數字加起來可被 3 整除。
  3. 四邊形：「小的可以說成大的」正方形都是長方形、菱形、平行四邊形；但反過來說就錯。口訣：小的可以說成大的，大的不可以說成小的。
  4. 商是幾位數，先看最高兩位被除數最高兩位夠不夠除？不夠 → 商少一位；夠 → 商多一位。不要一開始就硬除。
  5. 應用題四問圈關鍵詞（最多／最少／平均／還餘）→ 寫答句和單位 → 問「所有可能答案」就全部列出 → 用估算核對答案是否合理。
  1. 地球像一隻熟雞蛋薄薄的殼＝地殼、厚厚的蛋白＝地幔、圓圓的蛋黃＝地核。口訣：殼—幔—核。記住模型，三層就不會調亂。
  2. 影子：中午最短太陽升得越高，影子越短；太陽越低，影子越長。所以中午影子最短，早上影子偏西，傍晚影子偏東。
  3. 食物鏈的方向生產者（植物）→ 草食性動物 → 肉食性動物。箭嘴表示能量流向，由被吃的指向吃的。
  4. 天氣 ≠ 氣候天氣是短時間的狀況（今日下雨、明天下雨）；氣候是長時間的平均（香港是亞熱帶季風氣候，四季分明）。
  1. 3R 有次序Reduce（減少）→ Reuse（重用）→ Recycle（回收）。先減少，再重用，最後才回收——次序寫錯也會失分。
  2. 自轉 vs 公轉，一定要分清自轉一周約 24 小時 → 晝夜交替；公轉一周約 365.25 日 → 四季變化。題目問「為什麼有日夜」，答案是自轉。
  3. 季風：夏季西南，冬季東北夏季吹西南季風，帶來海洋的濕潤空氣，多雨；冬季吹東北季風，來自內陸，乾冷。
  4. 溫室效應因果鏈，背成一句燒燃料 → 排放 CO₂ → 溫室效應加劇 → 全球暖化 → 冰川融化 → 海平面上升 → 低窪地區被淹沒。
